### Triage Notes

**Verification:** Confirmed by inspection. The options tests' fake
`permission.hook` discards the callback, and the only test that runs setup
checks only that it succeeds. No test uses the real host adapter, so removing
the registration passes every test.

**Amendments:**

- A fake reviewer backend can be injected without module mocking: setup builds
  the fetch client with `FetchHttpClient.layer`, which reads the
  `FetchHttpClient.Fetch` reference at request time, so running setup under
  `Effect.provideService(FetchHttpClient.Fetch, fakeFetch)` replaces the network
  without changing the plugin entry point.
- Put these tests in a new test file; the options test file is about options.
  Existing fixtures for JWTs, OAuth credentials, the fake backend, and
  transcripts are in the oc-auto test-support files.
- The client retries transient failures with exponential backoff, so a failing
  backend test needs `TestClock` adjustment on a forked fiber, as the Codex
  client tests do.
